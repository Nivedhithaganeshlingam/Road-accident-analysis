# 🚦 Road Accident Analysis using Power BI

## 📌 Project Overview

The **Road Accident Analysis** project is an interactive Power BI dashboard designed to analyze road accident data and identify important patterns and trends. The dashboard provides insights into accident severity, casualties, accident trends, vehicle types, road conditions, and other key factors affecting road accidents.

The project helps users understand accident-related patterns through interactive visualizations and KPIs, making the data easier to analyze and interpret.

## 🎯 Objectives

* Analyze overall road accident and casualty statistics.
* Identify accident trends over time.
* Analyze accident severity and casualty distribution.
* Understand the impact of different vehicle types.
* Analyze accidents based on road and environmental conditions.
* Identify patterns that can support better road-safety decisions.
* Create an interactive and user-friendly Power BI dashboard.

## 📊 Key Dashboard Metrics

The dashboard provides important KPIs such as:

* Total Accidents
* Total Casualties
* Fatal Casualties
* Serious Casualties
* Slight Casualties
* Accident Severity
* Casualties by Vehicle Type
* Accidents by Road Type
* Accidents by Weather Conditions
* Accidents by Road Surface
* Year-wise Accident Trends

## 📈 Dashboard Features

### 1. Accident Overview

Provides a summary of total accidents and casualties using interactive KPI cards.

### 2. Accident Severity Analysis

Analyzes casualties according to different accident severity levels such as **Fatal, Serious, and Slight**.

### 3. Vehicle Analysis

Shows how different vehicle categories contribute to road accidents and casualties.

### 4. Time Analysis

Analyzes accident trends across different years, months, and time periods.

### 5. Road & Environmental Analysis

Provides insights into accidents based on:

* Road type
* Road surface conditions
* Weather conditions
* Light conditions

### 6. Interactive Dashboard

Users can interact with charts, slicers, and filters to explore specific accident categories and obtain detailed insights.
